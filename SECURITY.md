# Segurança

Não publique neste repositório:

- workbooks operacionais;
- dados pessoais ou identificadores corporativos;
- nomes de organizações, sistemas internos ou pessoas;
- URLs privadas, IDs de projeto ou nomes de arquivos reais;
- tokens, cookies, senhas, chaves, secrets ou valores de ambiente;
- atas, e-mails, transcrições, evidências ou documentos de terceiros e organizações.

Uma implantação derivada deve usar SSO corporativo, MFA, autorização por perfil, rate limiting, bloqueio progressivo, armazenamento seguro de secrets, criptografia, trilha de auditoria, validação de MIME, inspeção antimalware, retenção e monitoramento.

Vulnerabilidades não devem ser abertas como issue pública. Use um canal privado do mantenedor.
