# Checklist de implantação

## Fonte e governança

- [ ] Workbook oficial definido
- [ ] Tabela e cabeçalhos estáveis
- [ ] IDs únicos
- [ ] Responsáveis e critérios de aceite definidos
- [ ] Controle de versão habilitado
- [ ] Política de evidência e retenção definida

## Power Automate

- [ ] Caminho canônico configurado
- [ ] Conteúdo binário lido
- [ ] Endpoint autenticado
- [ ] Secret protegido
- [ ] Retry e alerta configurados
- [ ] Logs e correlação disponíveis
- [ ] Teste com alteração real concluído

## API e armazenamento

- [ ] Autenticação e autorização
- [ ] Validação de XLSX
- [ ] Limite e inspeção de upload
- [ ] Metadados de origem e horário
- [ ] Criptografia e retenção
- [ ] Observabilidade
- [ ] Rollback testado

## Board

- [ ] Visão executiva
- [ ] Roadmap navegável
- [ ] Consulta por ID
- [ ] Riscos e próximas ações
- [ ] Evidência e rastreabilidade
- [ ] Relatório individual
- [ ] Relatório semanal
- [ ] Controle de acesso
- [ ] Acessibilidade e responsividade

## Validação ponta a ponta

- [ ] Alterar ID de teste autorizado
- [ ] Salvar e reabrir Excel
- [ ] Confirmar execução do fluxo
- [ ] Confirmar HTTP 200
- [ ] Conferir metadados da fonte no board
- [ ] Conferir valores do ID no board
- [ ] Registrar evidência e resultado
